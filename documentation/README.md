# Mind V1 Blueprint & Artifact Documentation

This directory is reserved for offline institutional blueprint files, institutional agreement templates, and bulk onboarding templates:

- `mind_onboarding_template.xlsx`: Bulk user onboarding spreadsheet template with schema definitions for School Admin, Teachers, and Students.
- `institutional_data_processing_agreement.docx`: Model Data Processing Agreement (DPA) between the School (Data Fiduciary) and Mind (Data Processor) under the Indian DPDP Act, 2023.
- `icse_curriculum_taxonomy_v1.xlsx`: ICSE/ISC subject and topic mappings across Classes 6 through 12.
